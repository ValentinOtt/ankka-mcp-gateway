Privacy and analytics

Ankka keeps setup funnel events—page view and setup steps with public release/channel, coarse outcome and flow, a per-session key, country, browser family, and, for page views, the referring site—for three months in Cloudflare Analytics Engine. Analytics set no cookies and store no IP address, raw user agent, or identifier that outlives the session. Cloudflare separately processes hosted-zone reliability data. Self-hosted gateways do not report usage to Ankka. Prefer no analytics? Deploy from the public source repository instead.
